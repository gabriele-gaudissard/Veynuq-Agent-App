Local voice input

Speak instead of typing. The transcript appears in your message box for review and is never sent automatically.

The first use downloads a multilingual speech model (about 150 MB). Audio stays on this computer, in memory only. Recording starts only when you press Speak and stops after two minutes at most.

After downloading, dictation works offline without an account. Windows must allow this app to access your microphone.

Reusable procedures

        
Read-only schedules

        
Schedules can only read the project. Enable background schedules in Settings to run while the app is closed and you are signed in. No commands, file changes or desktop actions. A remote model still receives the required context.

        
        
        

        

      

    

    

      

        
Built-in tools

        
Tools for real actions

        

          Available directly in Veynuq. No plugins or accounts are needed for
          local work and public websites.
        

        

          Approval modes apply to every action. Accounts are only needed for
          private services; vision requires a compatible model.
        

        

        
All built-in tools are included and enabled by default. Turning a tool off removes it from the agent and blocks its execution. Permissions and external requirements still apply.

        
Optional tools

        
Remove plugins and Python tool environments managed by Veynuq. Built-in tools, models and conversations are kept. Components with unknown installation history are treated as user additions. Programs installed outside this inventory are not removed.

Plugins

        
Add skills, commands and MCP tools. Compatible components of Claude Code plugins can be imported from a folder.

        
External code runs with your Windows permissions when used. Review and trust the source. Command hooks run only through an approved tool action. Accounts are needed only for services that require them.
